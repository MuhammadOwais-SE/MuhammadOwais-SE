- **Own features end to end.** Django models, serializers and REST APIs through to the Svelte or Next.js interface, state management and API integration.
- **Fix what is quietly broken.** Traced a production-wide PDF and API failure to a misconfigured Django ManyToMany relation and restored report generation; migrated the reporting pipeline from xhtml2pdf to WeasyPrint to remove recurring layout failures.
